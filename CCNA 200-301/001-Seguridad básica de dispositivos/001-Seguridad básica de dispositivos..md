---
Cuando entramos a CLI de un dispositivo CISCO, el modo por defecto es "User EXEC" o "User Mode"
Este modo es muy limitado, solo podemos ver algunas cosas y no podemos hacer NINGÚN cambio.

Para poder configurar el dispositivo, tenemos que usar "PRIVILEGED EXEC MODE" usando el comando "enable"

Usando el comando "?" podemos ver todos los comandos disponibles en el modo en el que nos encontramos

![[Pasted image 20260825130817.png]]

Para poder ejecutar comandos de configuración, tenemos que entrar en "Global Configuration Mode" con el comando "conf t"
