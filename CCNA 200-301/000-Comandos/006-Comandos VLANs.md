

| Comando                               | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| show vlan brief                       | Muestra las VLANs en el swtich y que interfaz está en cada una                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| switchport mode access                | Configura una interfaz como accessport                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| switchport access vlan (nVlan)        | Asigna la VLAN a la interfaz                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| vlan (nVlan)                          | Entra en config mode de la VLAN nVlan (tmb para crear VLANs)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| name (nombre)                         | Cambia el nombre de la VLAN a nombre                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| switchport mode trunk                 | Configura la interfaz en modo Trunk Port                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| switchport trunk ecapsulation dot1q   | Configura la encapsulación a 802.1Q (solo es necesario en los swiths que soportan 802.1Q y ISL)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| show interfaces trunk                 | Muestra información sobre interfaces trunk                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| switchport trunk allowed vlan         | Configura las VLANs permitidas en el Switch. Tiene varias opciones:                 - WORD (VLAN IDs) para añadir VLANS por su ID                                              - add añade la VLANs a la lista actual                                                                 - all permite todas las VLANS                                                                              - except permite todas las VLANs menos la siguiente a esa palabra                  - none excluye todas las VLANS                                                                          - remove elimina VLANs de la lista |
| switchport trunk native vlan (vlanID) | Cambia la VLAN nativa de la interfaz.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| show vlan brief                       | Muestra los access ports asignados a cada VLAN, NO los trunk ports. PAra eso esamos show interface trunk.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ip routing                            | Dentro de switchs multicapa, permite que cree su tabla de routing y pueda enrutar y funcionar como un router                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
