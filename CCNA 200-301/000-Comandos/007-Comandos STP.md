#comandosSTP #comandos 

| Comando                                        | Descripción                                                            |
| ---------------------------------------------- | ---------------------------------------------------------------------- |
| spanning-tree mode (modo)                      | Configura el tipo de STP de la interfaz                                |
| spanning-tree vlan (num vlan) root primary     | Configura la interfaz como root                                        |
| spanning-tree portfast                         | Configura PortFast en la interfaz                                      |
| spanning-tree portfast default                 | Configura PortFast en todos los access ports del SW                    |
| show spanning-tree interface (interfaz) detail | Muestra información detallada sobre STP en la interfaz correspondiente |
| spanning-tree bpduguard enable                 | Activa BPDU Guard en una interfaz                                      |
| spanning-tree portfast bpduguard default       | Activa BPDU Guard en todas las interfaces                              |
| spanning-tree bpduguard disable                | Desactiva BPDU Guard de una interfaz                                   |
| spanning-tree bpdufilter enable                | Activa BPDU Filter en un puerto/interfaz                               |
