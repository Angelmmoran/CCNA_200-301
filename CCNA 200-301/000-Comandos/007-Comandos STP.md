#comandosSTP #comandos 

| Comando                                    | Descripción                                         |
| ------------------------------------------ | --------------------------------------------------- |
| spanning-tree mode (modo)                  | Configura el tipo de STP de la interfaz             |
| spanning-tree vlan (num vlan) root primary | Configura la interfaz como root                     |
| spanning-tree portfast                     | Configura PortFast en la interfaz                   |
| spanning-tree portfast default             | Configura PortFast en todos los access ports del SW |
