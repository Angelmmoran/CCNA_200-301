#comandosIPv4


|                Comando                 |                                                  Descripción                                                  |
| :------------------------------------: | :-----------------------------------------------------------------------------------------------------------: |
| show ip interface brief (sh ip int br) |                     Muestra información sobre las interfaces conectadas a un dispositivo.                     |
|      interface (nombre interfaz)       |                   Dentro del modo config t nos permite configurar la interfaz que queramos.                   |
|       ip address (dirección IP)        | Asigna la dirección IP a la interfaz que estemos configurando. También tenemos que escribir la máscara de IP. |
|              no shutdown               |                               Cancela el comando shutdown que viene por defecto                               |
|   show interfaces (nombre interfaz)    |                             Muestra información sobre la interfaz (capa 1, 2 y 3)                             |
|      show interfaces description       |             Muestra la descripción de la interfaz (esta descripción tiene que ser escrita a mano)             |
|          description (texto)           | Desde la configuración de la interfaz (comando interface) nos permite asignar una descripción al dispositivo. |
